Тарифы на подключение

Единственная страница стенда, подключающая собранный файл. Требует предварительного npm run build.

Что здесь проверяется

  • Подключение одной строкой: ни модуля, ни отдельного файла стилей (FR-01).
  • В консоли пусто: логгер вырезан из продакшен-сборки.
  • Без ?kalka и при пустом хранилище Object.keys(window).filter((k) => /kalka/i.test(k)) даёт пустой массив — виджет не пишет в глобальную область.
  • window.__kalka.unmount() возвращает страницу в исходное состояние.

Если дев-сервер не отдаёт ../dist/kalka.js, страницу можно открыть прямо из файловой системы: бандл — классический скрипт, этого достаточно. Под file:// браузер может запретить доступ к хранилищу; это ожидаемо, и тогда активация работает только через ?kalka.
