# Метки триажа

Скиллы говорят в терминах пяти канонических ролей триажа. Этот файл сопоставляет
роли с реальными строками меток, принятыми в трекере этого репозитория.

| Метка в mattpocock/skills | Метка в нашем трекере | Значение |
| --- | --- | --- |
| `needs-triage`    | `needs-triage`    | Требуется оценка мейнтейнера |
| `needs-info`      | `needs-info`      | Ждём уточнений от автора задачи |
| `ready-for-agent` | `ready-for-agent` | Полностью описана, готова для автономного агента |
| `ready-for-human` | `ready-for-human` | Требует человека |
| `wontfix`         | `wontfix`         | Делать не будем |

Когда скилл упоминает роль (например, «поставь метку готовности для агента»),
использовать соответствующую строку из таблицы.

Трекер — локальный markdown, поэтому метка пишется строкой `Status: <метка>`
вверху файла задачи. Правый столбец можно менять под свою терминологию.
