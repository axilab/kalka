# Базовые правила проекта «Калька»

> Кода в репозитории ещё нет, поэтому эти правила **не выведены из кодовой базы**,
> а выбраны под ограничения PRD (TypeScript, Preact в Shadow DOM, Vite library mode,
> бандл ≤ 100 КБ gzip, отсутствие сети). Правьте по мере появления реального кода.

## Соглашения об именовании

- Файлы: `kebab-case.ts`, компоненты Preact — `PascalCase.tsx`
- Переменные и функции: `camelCase`
- Классы и типы: `PascalCase`
- Константы модульного уровня: `UPPER_SNAKE_CASE`
- Поля JSON-формата обмена: `camelCase` (`exportedAt`, `fontSize`) — соответствует
  примеру из PRD, раздел 9. Имена полей — часть контракта, менять их нельзя
  без повышения `format`

## Структура модулей

Структура задаётся Feature-Sliced Design, полное описание — в
`.ai-factory/ARCHITECTURE.md`. Здесь только то, что касается повседневного написания кода:

- Папки слайсов и сегментов — `kebab-case`: `edit-text`, `tool-palette`
- У каждого слайса есть `index.ts` — единственная точка входа снаружи.
  `export *` в нём не используется: барели расходуют бюджет бандла
- Импорт только из слоёв строго ниже; слайсы одного слоя друг друга не импортируют
- Слово `widget` в коде означает слой FSD, а не продукт. Продукт — «Калька» / `kalka`
- Код, трогающий DOM сайта-носителя, его `history` и глобальную область, живёт только
  в `app/index.ts`, `app/lib/mount.ts`, `app/lib/overlay` и `shared/lib/dom`
  и отделён от компонентов интерфейса: у них разные правила безопасности и разный
  жизненный цикл. Компоненты слоёв `pages`, `widgets` и `shared/ui` чужой DOM
  не трогают вовсе
- Внутрь виджета не тянутся зависимости без явной необходимости — каждая
  расходует бюджет в 100 КБ gzip

## Обработка ошибок

- Ошибка внутри виджета никогда не должна ломать сайт-носитель (NFR-06).
  Публичные точки входа и обработчики событий оборачиваются так, чтобы
  исключение не всплывало в код носителя
- Ошибки не отправляются наружу и не логируются в сторонние сервисы (NFR-03)
- Правка, которую не удалось наложить, не исчезает молча: она помечается
  как «якорь уехал» и остаётся видимой в списке (Ц4, FR-20, FR-31)
- Невалидный импортируемый файл отклоняется с понятным сообщением, а не
  частично применяется

## Поток управления

- Предпочитать плоский, читаемый поток управления глубоко вложенным условиям.
  Использовать guard clauses, ранние `return`/`continue`, небольшие именованные
  вспомогательные функции или явную классифицирующую логику там, где это делает
  код понятнее. Пограничные и неинтересные случаи обрабатывать в начале,
  чтобы основной путь оставался на виду
- Стратегия анкоринга с откатом (селектор → XPath → фрагмент) пишется как явная
  последовательность попыток с понятным результатом, а не как вложенные условия

## Логирование

- В продакшен-сборке виджет молчит: никаких `console.log` в отгружаемом бандле
- Диагностический вывод допустим только под флагом отладки, который выключен
  по умолчанию и вырезается сборкой

## Интерфейс

- Весь пользовательский текст — по-русски, без технических терминов.
  Рецензент не видит слов «селектор», «якорь», «DOM», «JSON» (FR-36).
  Технические термины остаются в коде, комментариях и именах переменных

## Формат обмена и ИИ-агент

- Главный потребитель экспортируемого файла — ИИ-агент, а не человек. Поля формата
  оцениваются по тому, поднимают ли они долю автоприменения (метрика M7), а не
  по тому, красиво ли выглядит JSON
- В файл не попадает ничего, что агент мог бы принять за команду: ни путей к файлам,
  ни shell-команд, ни ссылок на инструкции (FR-46). Только описание изменений контента
- Содержимое `now` и `note` — данные, введённые заказчиком. Виджет их не интерпретирует
  и не переносит в поля, которые агент читает как настройки
- Шапка `about` генерируется константой, а не собирается из пользовательских данных
- Оформление живёт в отдельном поле `style` и никогда не подмешивается в `now`:
  иначе агент применит инлайновый CSS прямо в исходники
- Тип записи — ровно один из `text-override`, `style-wish`, `comment` (FR-39).
  Автоматически применяется только первый

## Приватность

- Никаких сетевых запросов из виджета. Ни телеметрии, ни отчётов об ошибках,
  ни загрузки шрифтов и стилей с CDN. Всё, что нужно виджету, лежит в бандле
